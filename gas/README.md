# GASによる週報スプレッドシート自動セットアップ

`週報セットアップ.gs` を実行すると、設計v1のテーブル構成を **スプレッドシートに一発で構築** します。
（テーブル設計の詳細は `../docs/週報スプレッドシート_テーブル設計_叩き台.md` を参照）

## できること

- シート自動生成：`M_大分類` / `M_担当者` / `M_案件` / `T_タスク` / `ダッシュボード`
- ヘッダー・書式（太字・ヘッダー色・1行目固定・列幅・日付/数値フォーマット）
- **プルダウン（入力規則）** を自動設定
  - `T_タスク`：案件名・区分（予定/実績）・担当者名・大分類名・ステータス
  - `M_案件`：大分類名・担当者名・ステータス
  - → いずれも **マスタ参照** なので表記ゆれが起きない（円グラフが割れない）
- `M_案件.累計作業時間` を **自動集計**（`T_タスク`の実績を案件名で `SUMIFS`）
- **ダッシュボード** を自動構築
  - 大分類別 実績時間の集計表 ＋ **円グラフ**
  - 期間フィルタ（`B1`=開始 / `B2`=終了）で日・週の絞り込み
  - **ドリルダウン**：`E1` で大分類を選ぶと、その分類の **案件別 実績時間** を `QUERY` で表示

## 設計との差分（実装上の判断）

- 設計ドキュメントでは結合キーを **ID** としているが、スプレッドシート実装では
  プルダウンで **「名前」を選ばせる**方式にしている（人が読める＋マスタ参照で表記ゆれ防止）。
- `大分類ID`・`担当者ID`・`案件ID` の列はマスタに残しているので、
  将来DB移行やID結合が必要になっても対応可能。

## 使い方

1. 対象のスプレッドシートを開く
2. **拡張機能 → Apps Script** を開く
3. `週報セットアップ.gs` の中身を貼り付けて保存
4. 関数 **`setupWeeklyReport`** を実行（初回のみ権限承認）
5. 完了後、スプレッドシートに戻るとメニュー **「週報ツール」→「セットアップ実行」** からも再実行可能

## 特徴・注意

- **冪等**：何度実行してもOK。既存シートの入力データは消さず、ヘッダー・入力規則・数式のみ再適用。
- マスタ（大分類・担当者）の **サンプル行は「空のときだけ」** 投入。実データ投入後は上書きしない。
- `SEED_大分類` / `SEED_担当者` を編集すれば、初期投入する分類・担当者を変更できる。
- 円グラフ・ドリルダウンは `T_タスク` の **区分=実績** 行だけを集計する。
